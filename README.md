## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Diagram Library** | Organize OmniGraffle files by type, project and revision |
| **Stencil Manager** | Track installed stencil libraries with category and usage |
| **Style Standards** | Document line, color and shape style standards per diagram type |
| **Review Tracker** | Track diagram review cycles and approval status per file |
